# Быстрое перепланирование MDVRP после отмены клиентов

Код к решению тестовой задачи № 1. Реализованы:

- `ExactDP`: точное решение MDVRP на небольшом числе клиентов и сохранение ответов для всех подмножеств через `precompute()`;
- `replan()`: удаление отменённых клиентов и точная переоптимизация небольших групп маршрутов при заданном лимите времени;
- `qubo()`: построение коэффициентов QUBO для того же набора ограничений;
- `verify_mdvrp.py`: независимые проверки на малых экземплярах, в том числе с запрещёнными дугами.

Нужен Python 3.10 или новее; внешние библиотеки не требуются.

```bash
python mdvrp.py
python verify_mdvrp.py
```

Демонстрация в `mdvrp.py` показывает случай, где после отмены клиента простое сокращение маршрута стоит 100, а перепланирование находит маршрут стоимостью 3.

`ExactDP` возвращает доказанный оптимум или сообщает о недопустимости; его время экспоненциально зависит от числа клиентов. `replan()` возвращает допустимое решение и не заявляет глобальную оптимальность, если не оптимизирован весь парк сразу. Вес `math.inf` обозначает запрещённую дугу.
